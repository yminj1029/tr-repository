
# tr-repository

**MentalHealthChart**는 Jotai, VisX, D3.js, 그리고 Next.js를 사용하여 개발 중인 심리 검사 결과 시각화 프로젝트입니다.

## 주요 기능
- **데이터 입력 및 비교:**
  - 각 컬럼에 숫자를 입력할 수 있으며, 입력한 숫자의 크기를 자동으로 비교해줍니다.
  - 비교 결과를 **복사**할 수 있는 기능이 포함되어 있습니다.

- **차트 시각화:**
  - VisX와 D3.js를 사용하여 **바 차트**와 **거미줄 차트(레이더 차트)** 형태로 데이터를 시각화합니다.

- **PDF 내보내기 (진행 중):**
  - 차트와 데이터 시각화 결과를 **PDF 파일로 내보내기** 기능을 개발 중입니다.

## 사용 기술 스택
- **Frontend:** Next.js, Jotai
- **Data Visualization:** VisX, D3.js
- **PDF Export:** (진행 중)

이 프로젝트는 현재 개발 중이며, 기능이 계속 추가될 예정입니다.
